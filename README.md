# thewondermoms

This is a static landing page for a motherhood and baby care brand.

## Quick deploy

1. Push the repository to GitHub (it is already connected if you published from GitHub Desktop).
2. Go to https://vercel.com and log in.
3. Click `New Project` and import `vanya811w/thewondermoms.com`.
4. Choose `Other` for framework preset.
5. Leave build command and output directory empty.
6. Deploy the project.

## Local files

- `index.html` — page structure and article content.
- `styles.css` — page styling and layout.
- `vercel.json` — static deployment config for Vercel.
- `.github/workflows/vercel-deploy.yml` — optional GitHub Actions deploy workflow.
